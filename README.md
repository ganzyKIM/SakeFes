# 사케페스 완전정복

2026 서울 사케 페스티벌(5월 23~24일) 현장에서 쓰는 가이드 웹앱.
부스 180곳과 사케 682종 정보를 들고 다니면서, 마신 걸 체크하고 다음에 갈 곳을 추천받는다.

행사장은 통신이 잘 안 터진다. 그래서 서비스 워커로 전부 캐싱해 **오프라인에서 그대로 돌아가게** 만들었다.

## 기능

- **부스 지도** — 배치도 위에 그리드를 얹어 부스 코드로 위치를 찾는다. A~R 14개 구역.
- **부스·사케 정보** — 부스 소개 180개, 사케 설명 682개. 일본주도, 정미보합, 쌀 품종, 추천 음용 온도까지.
- **체크·메모·평점** — 마신 사케를 체크하고 메모를 남긴다. 전부 `localStorage` 에 쌓인다.
- **필터** — 전체 / 체크한 것 / 정보 있는 것
- **다음 동선 추천** — 체크 상태를 보고 아직 안 간 부스 중 가까운 곳을 제안한다.
- **이벤트 일정** — 토·일 나눠서 표시.
- **알림** — 브라우저 알림 권한을 받아 시간대별 이벤트를 알려준다.
- **데이터 내보내기·가져오기** — 기기를 바꾸거나 일행과 기록을 합칠 때 쓴다.
- **PWA** — 홈 화면에 설치된다. iOS 는 설치 방법이 달라서 별도 안내 바를 띄운다.

## 데이터

| 파일 | 내용 |
|---|---|
| `booth_info.json` | 부스 소개 180개 |
| `sake_info.json` | 부스별 사케 설명 682개 |
| `data.js` | 노션 DB 에서 뽑아낸 부스·사케 원본 |
| `booth_map.jpg` | 행사장 배치도 |
| `images/` | 사케 사진 259장 |

## 실행

`LOCAL_SERVER.bat` 을 실행하거나, 아무 정적 서버로 폴더를 열면 된다.
서비스 워커 때문에 `file://` 로는 제대로 동작하지 않는다.

## 배포

Surge 로 올린다.

```
DEPLOY_SURGE.bat
```

`.surgeignore` 에서 `node_modules`, 배치 파일, 백업 파일을 걸러낸다.

## 저장소 메모

이 저장소에는 이 문서만 둔다. 실제 자산은 로컬에 있다.

- `images/` 는 259장 130MB 라 깃에 올릴 물건이 아니다.
- `data.js` 에는 노션이 발급한 S3 프리사인 URL 이 95개 들어 있다. 서명이 붙은 주소라 공개 저장소에 둘 이유가 없다. 어차피 만료돼서 쓸모도 없다.
- `localStorage` 키는 `ssf26v4`(체크·메모), `ssf26rt`(동선), `ssf26_alerts`(알림). 스키마를 바꾸면 키 뒤 숫자를 올려야 기존 사용자 데이터와 안 부딪힌다.
