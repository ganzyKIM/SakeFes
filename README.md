# 사케페스 완전정복

2026 서울 사케 페스티벌(5월 23~24일) 관람객용 가이드 웹앱입니다.
배포 주소는 https://seoul-sake-festival.surge.sh/ 입니다.

이 저장소에는 설명 문서만 있습니다.
앱 소스는 공개하지 않았습니다.

## 기능

- 부스 지도: 배치도 위 격자에서 부스 코드로 위치 찾기. 14개 구역, 부스 180곳
- 사케 정보: 부스 소개 180개, 사케 설명 682개. 설명에 일본주도와 정미보합 포함
- 사케 체크: 마신 사케에 체크, 평점, 메모, 사진 기록. 목록에 없는 사케 추가 가능
- 목록 필터: 전체, 정보 있음, 체크 완료, 1관, 2관
- 날짜별 루트: 꼭 갈 부스를 토요일 또는 일요일 루트에 담고 순서 조정
- 이벤트 일정: 세미나와 유료 시음 시간표. 시작 전 브라우저 알림 신청 가능
- 기록 내보내기와 가져오기: JSON 파일. 기기를 바꾸거나 일행과 기록을 맞출 때 사용
- 홈 화면 설치(PWA). iOS에는 설치 방법 안내 표시

기록은 브라우저 `localStorage`에만 저장됩니다.
서버는 없습니다.

## 소스 구성

아래 파일은 비공개 소스에 있고, 이 저장소에는 없습니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 앱 화면과 스크립트 |
| `data.js` | 노션 DB에서 뽑은 부스별 사케 원본 |
| `booth_info.json` | 부스 소개 180개 |
| `sake_info.json` | 부스별 사케 설명 682개 |
| `sw.js` | 서비스 워커. 이벤트 알림 예약 |
| `manifest.json` | PWA 설정 |
| `booth_map.jpg` | 행사장 배치도 |
| `images/` | 사케 사진 |

로컬 확인과 배포용 배치 파일(`LOCAL_SERVER.bat`, `DEPLOY_SURGE.bat`)도 비공개 소스에 있습니다.
서비스 워커는 `file://`에서 등록되지 않습니다.
로컬에서 열 때는 정적 서버가 필요합니다.

## 소스를 올리지 않은 이유

- `images/`는 사진 259장, 130MB입니다.
- `data.js`에는 노션이 발급한 S3 서명 URL이 들어 있습니다. 지금은 만료된 주소입니다.

## 저장 키

`localStorage` 키는 세 개입니다.

| 키 | 내용 |
|---|---|
| `ssf26v4` | 부스별 체크 기록과 메모 |
| `ssf26rt` | 날짜별 루트 |
| `ssf26_alerts` | 알림 신청 |

저장 형식을 바꾸면 키 뒤 숫자를 올립니다.
기존 사용자의 기록과 섞이지 않게 하기 위해서입니다.
